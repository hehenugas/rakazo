# Phase 21 — Transcript, Voice, Approvals & Connect Apps Experience Parity

## Objective

Close the remaining interaction-state gaps around conversation cards, voice memos, approvals, credential handoff, and plugin discovery.

## Scope

- voice memo transcript synchronized to playback
- click transcript word/segment to seek
- concise approval summary with full request behind disclosure
- secure login/credential request UX using existing secret boundaries
- Connect apps remains the entry point
- Marketplace/search language follows current plugin-centric reference
- sign-in resumes the interrupted Bot task where possible
- featured plugin treatment may be approximated structurally; exact logo pixel placement is not required

## DONE Gate

The user can understand and recover from important conversation states with the same learned actions as Grok Bot, without exposing technical/security machinery unnecessarily.
