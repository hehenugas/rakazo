# Phase 08 — Mobile Parity

## Objective

Bring the new product model to Expo mobile with mobile-native navigation rather than shrinking the desktop three-column layout.

## Required Surfaces

Coworker roster, Search, New Chat, conversation, Details, Tasks/Projects, Routines, Library, Team Bots, Main Bot, Connect Apps where feasible, voice memo, draft actions, and computer takeover.

Desktop side panels become mobile screens/sheets/stacks. Preserve semantic parity, not pixel parity.

## DONE Gate

Critical M1 workflows work from mobile and mobile-specific accessibility/performance verification passes.
