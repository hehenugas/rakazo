# Phase 03 — Routines, Library & Search

## Objective

Reframe existing Rakazo capabilities into Grok-like Bot-level surfaces instead of rebuilding their engines.

## Routines

Keep the existing routine engine and triggers. Rework discovery and presentation around:

- Bot-level list
- active/paused state
- schedule/event summary
- create/edit
- Run now
- history
- GitHub/message/webhook triggers where supported

No node-canvas workflow builder.

## Library

Create a Bot-scoped projection of artifacts/files/links/pages/media with chronological grouping and source deep links.

## Search

Use a Search action/command surface that prioritizes Bots/actions/Routines/settings before content matches while preserving global search.

## DONE Gate

Existing Routine functionality remains intact, Bot Library is useful, and Search is reachable through the new shell with complete E2E coverage.
