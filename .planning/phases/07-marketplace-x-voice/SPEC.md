# Phase 07 — Connect Apps, X & Voice Memo

## Objective

Productize integrations as `Connect apps`, add a first-class X capability pack through provider-neutral connector infrastructure, and add voice memo messages.

## Connect Apps

Support featured apps, browse/search, connected state, multiple accounts where supported, capability preview, management, and advanced custom MCP/API/OpenAPI paths.

## X Capability Pack

Expose only capabilities actually supported by the configured connector/provider. Consequential actions remain approval-gated.

## Voice Memo

Add a message block/artifact with audio, duration, transcript, playback, and optional word timing.

## DONE Gate

Connect Apps is usable, X is capability-gated, and voice memo works end-to-end with safe storage/playback.
