# Phase 23 — Cross-Platform Experience Parity Release Gate

## Objective

Verify M3 as real user journeys across web, Electron, and mobile. Do not use pixel identity as a release criterion.

## Release Standard

A Grok Bot user should be able to:

- schedule recurring work
- manage routines
- publish/use Team Bots
- compose/retry messages
- review approvals and voice memos
- connect/sign in to apps
- start/stop Projects and delegated work
- understand Main Bot attention

without learning a materially different product model.

## Evidence

Use journey E2E, integration/authorization tests, deterministic hierarchy screenshots, accessibility review, performance/realtime review, and current official reference documentation.

## DONE Gate

All phases 17–22 are DONE, no known P0/P1 journey parity delta remains, full CI is green, and maintainer experience review approves M3.
